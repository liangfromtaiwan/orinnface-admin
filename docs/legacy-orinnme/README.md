# ⚠️ 旧 OrinnME 時代のドキュメント(現行仕様ではない)

このディレクトリのファイルは `orinnme-admin` から複製した際に引き継いだもので、
**OrinnME(疲労度分析)** の製品モデルを前提にしている。2026-05 頃の作業記録。

`orinnFACE 管理画面仕様書 v1.0`(2026-08-18)とは互換性がない。主な相違:

| 旧ドキュメントの前提 | v1.0 の正 |
|---|---|
| `admin` / `oem` / `b2b` の3視点を query string で切替 | `operator` / `company_admin` / `store_admin` / `store_staff` の membership scope |
| 疲労度、主観 vs AI のズレ警告 | neutral 6指標 / 5動作可動域 / 姿勢(B2Bのみ) |
| `張り(強)`〜`ゆらぎ(弱)`、`軽やか`〜`踏ん張りどき` | v1.0 に存在しない |
| 店舗が自由に動画を追加 | 固定13枠への差し替え申請 + 本部承認 |
| 生画像は無期限 | 登録2年 rolling / Guest・未連携 180日 |
| B2B Guest | 未登録顧客の仮データ / 未連携分析 |

**参照するなら履歴目的のみ。** 現行の実装判断は必ず以下を使うこと:

- `/CLAUDE.md` — 実装指針
- `/docs/ADMIN_SPEC_v1.0.md` — 仕様書 v1.0 全文抽出
